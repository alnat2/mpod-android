# Automatic Release Versioning Rule

## Обязательный инкремент версии перед пушем в main

Перед каждым пушем коммитов в ветку `main`, содержащих изменения в кодовой базе приложения (`app/src/` или конфигурации сборки/зависимостей), агент **обязан** инкрементировать версию приложения в `app/build.gradle.kts`:

1. `versionCode`: увеличить строго на `+1` (например, `26` → `27`).
2. `versionName`: увеличить патч-версию семантического версионирования (например, `"1.0.25"` → `"1.0.26"`).

### Исключения:
- Изменения, затрагивающие **исключительно** документацию (файлы в `docs/`, `*.md` документация, комментарии к PR), версию не инкрементируют.
- Если в рамках одного рабочего сеанса делается серия связанных коммитов (например, пошаговые шаги 1 → 2 → 3), версию допустимо поднять финальным коммитом перед отправкой (`push`) всей серии изменений в удалённую ветку `main`.
