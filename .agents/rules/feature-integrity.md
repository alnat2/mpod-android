# Feature Integrity Rules

## Rule 1: Real-world Input Matrix
При проектировании и реализации фич импорта, шаринга и обработки внешних ссылок обязательна проверка на матрице реальных форматов:
- Прямые аудиофайлы (`.mp3`, `.m4a`, direct streams);
- Платформенные ссылки экосистем (Apple Podcasts URL с `?i=...` и без `?i=...`, Castbox и др.);
- Обычные HTML веб-страницы с тегами `og:audio` и `<audio src="...">`;
- Ошибочные/битые ссылки (страницы без аудио, 404, невалидные URL).

Запрещено сдавать задачу, протестировав только синтетический happy-path (например, идеальный локальный `.mp3`). При ошибках резолвинга/загрузки база данных и плейлист не должны загрязняться неработающими элементами, а UI обязан отображать информативное сообщение.

## Rule 2: Zero Local Status Duplication
Полный запрет на приватные `StatusCard`, локальные `ErrorBanner` и кастомные плашки уведомлений внутри отдельных экранов.
- Любые статусы, предупреждения, индикаторы загрузки и ошибки на всех экранах приложения должны отображаться исключительно через канонический компонент `MpodStatusBanner` из `com.example.mpod.ui.components.MpodUi`.
- Компонент должен строго соответствовать 4 каноническим состояниям Figma (секция `1669:19872`):
  1. **Error + Action** (`1613:3282`): бордер 1px `#e7000b`, отступы 16dp, кнопка действия 32dp с обводкой 1px.
  2. **Notice + Action** (`1613:3298`): бордер 1px `outline`, отступы 16dp, кнопка действия 32dp с обводкой 1px.
  3. **Notice + Dismiss** (`1613:9900`): бордер 1px `outline`, отступы 16dp, кнопка закрытия 44×44dp с зеленым крестиком `primary`.
  4. **Error + Dismiss** (`1669:19859`): бордер 1px `#e7000b`, отступы 16dp, кнопка закрытия 44×44dp с зеленым крестиком `primary`.

## Rule 3: Cross-screen Refactor Sweep
Любое изменение или редизайн глобального визуального паттерна (баннеры, кнопки, карточки, диалоги, списки) обязано сопровождаться аудитом по всей кодовой базе:
- Выполнить поиск по проекту (`grep_search`) всех существующих использований и аналогичных локальных компонентов.
- Заменить устаревшие или самописные реализации на всех экранах приложения в рамках одного таска, не оставляя легаси на соседних экранах.
